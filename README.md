# BatteryScientist Web

与 `../batteryscientist` 平级的科研工作台。React + TypeScript + Vite + Ant Design，FastAPI 服务层位于后端 `batteryscientist/api/`。研究状态及产物继续保存在原项目目录，SQLite 只保存项目登记、Web 运行记录与事件。

## 启动

需要 Node.js >=22.12，建议 npm >=9.5。当前机器已有的 npm 9.2 已完成安装及构建验证，但部分开发依赖声明要求更新版本。

```bash
cd /home/xinghaohuang/batteryscientist
/data/apps/micromamba/envs/xinghao/bin/python -m pip install -e '.[web,test]'

cd /home/xinghaohuang/batteryscientist-web
npm ci
npm run dev:all
```

打开 http://127.0.0.1:5173 。后端监听 http://127.0.0.1:8000，API 文档通过前端 `/api/docs` 访问。

也可分别运行后端 `./run-web-api` 与前端 `npm run dev`。已有服务占用端口时，不要重复启动。远程开发可通过 SSH 转发前端端口：

```bash
ssh -L 5173:127.0.0.1:5173 your-server
```

Vite 的代理目标使用启动进程环境变量 `BATTERYSCIENTIST_API_URL`；例如 `BATTERYSCIENTIST_API_URL=http://127.0.0.1:8002 npm run dev`。后端路径由 `BATTERYSCIENTIST_BACKEND_DIR` 指定，运行解释器由 `BATTERYSCIENTIST_RUNTIME_PYTHON` 指定，默认沿用项目的 xinghao 环境。

## 当前功能

- 根路径 `/` 是产品首页（Landing）：介绍 11 阶段研究流程与主要能力，显示研究项目数和运行中项目数，点“进入工作台”进入 `/projects`。左侧导航的电池图标回到首页。
- `/projects` 自动发现默认项目根目录中的已有工作流；支持新建、导入和搜索项目。可直接输入研究问题开始研究，“等你处理”列出待审阅项目。
- 工作台顶部 11 段研究进度条：显示已完成、进行中、等你审阅等状态，点击阶段打开对应产物；报告和公式渲染、图片与 PDF 预览、文件下载。
- 本地加载 Monaco 编辑器；文件保存前检查 SHA256，运行期间禁止从界面修改产物；未保存内容离开时确认。
- 协作方式（专家模式 / 全自动，选中项分别以紫色和青色高亮）直接在输入框下方切换；“运行设置”配置起始与停止节点、恢复节点、模型和运行参数。
- 专家摘要、研究问题与反馈提交；提交和实际执行前均核对产物版本。
- 独立进程执行、停止进程树、持久化事件、SSE 自动重连；SSE 连通时只靠事件刷新，断线时回到轮询兜底。
- 实验 manifest 任务表、运行日志、运行历史。
- 识别 CLI 启动的工作流并展示终端来源，不接管其生命周期。
- 物理实验室：新威 BTS 设备/单元/通道监控、状态筛选、测量值和通道详情；自动化扣电页签预留。

## 开发结构

```text
src/
  app/                 # 应用布局、路由；theme.css 主题变量、shell.css 导航栏、effects.css 通用动效
  api/                 # 请求封装、OpenAPI 生成的接口类型
  components/          # 共用视图组件
  components/fx/       # 动效：粒子背景、能量爆发、数字滚动、鼠标光晕与卡片倾斜、充能跳转
  features/landing/    # 产品首页：循环老化示意动画（CycleLab）、研究流程、能力介绍
  features/projects/   # 项目列表和创建/导入
  features/laboratory/ # 物理实验室、BTS 通道监控
  features/workbench/  # 工作台、研究进度条（ChargeTrack）、运行配置、产物编辑、专家审阅
  lib/                 # 通用格式化函数
scripts/               # 开发启动、接口类型生成、隔离测试服务
tests/                # Playwright 端到端回归
deploy/               # nginx / systemd 部署示例
```

```bash
npm run api:generate  # 后端接口变动后重新生成 src/api/schema.d.ts，无需启动服务
npm run typecheck
npm run lint
npm run format:check
npm run build
npx playwright install chromium
npm test
```

接口类型全部来自后端 OpenAPI：后端每个返回 JSON 的接口都声明了 Pydantic 响应模型（`batteryscientist/api/schemas.py`），`npm run api:generate` 据此生成 `src/api/schema.d.ts`，`src/api/client.ts` 只从中取类型别名，不再手写接口类型。唯一例外是方案画布草稿 `CanvasDraft`，它沿用 React Flow 自身的节点和连线类型。后端字段有变化时先改模型、再重新生成，类型检查会指出前端需要跟着改的地方。

如果机器已有 Chromium，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chrome npm test` 指定。测试使用临时项目目录和独立端口 8001/5174，审阅运行请求由浏览器拦截，不启动真实模型或 GPU 实验。

## 运行与部署边界

本版本面向单用户使用，支持本机 / SSH 隧道以及下述带登录保护的公网部署。API 默认仅监听回环地址并限制 Host 与 Origin；尚未提供多租户权限。`deploy/` 提供构建后静态文件与 API 同源部署示例；正式远程部署应接入现有身份认证层。

Web 运行采用全局单项目并发策略，项目内并发交给已有实验调度器。终端 CLI 仍可独立运行：Web 启动前会检测已登记项目的终端进程，但无法阻止用户随后从终端另启任务；同一项目应统一选择一种运行入口。

“停止运行”会请求中断执行进程及其子进程，并保留已保存文件；恢复通过已有节点入口和实验回执继续，不承诺恢复未落盘的模型对话或训练内存。浏览器关闭、API 正常重启不影响独立研究进程；机器重启后会标记为已中断，不自动重启实验。

实验页目前展示任务定义，完成状态仍应结合 tracker、日志和回执确认。Wiki 图谱、多用户、跨项目 GPU 调度、配置编辑和指标对比为后续扩展。

后端管理数据默认位于 `../batteryscientist/.batteryscientist/web/`。备份时一并保存该目录和研究项目文件；这部分数据不是前端构建产物。

## 当前公网部署

- 前端：`https://www.xora.top`（Vercel，框架 Vite，Node.js 22）。
- `/api/*` 通过 Vercel 外部 rewrite 转发到 `https://api.xora.top/api/*`，浏览器保持同源请求。
- 后端：Cloudflare Tunnel → `127.0.0.1:8000`；隧道重写 Host 为 `localhost`。
- 单用户登录：scrypt 密码摘要、12 小时服务端会话、HttpOnly/Secure/SameSite Cookie、登录限速、Origin 校验。下载、日志、事件流及 API 文档同样受保护。
- 配置和凭据：`~/.config/batteryscientist/`；初始登录信息位于该目录下的 `login.txt`，仅所有者可读。不要提交或发送 Tunnel 凭据。
- 服务：`batteryscientist-api.service`、`batteryscientist-tunnel.service`，均为用户 systemd 服务；已启用 linger。

```bash
systemctl --user status batteryscientist-api batteryscientist-tunnel
journalctl --user -u batteryscientist-api -u batteryscientist-tunnel -n 100
systemctl --user restart batteryscientist-api
```

网络连通检查使用 `/api/auth/session`；未登录请求 `/api/health` 应返回 401。API 重启会保留研究进程及已落盘的登录会话。Tunnel 重启不会终止研究进程，事件连接会重连。修改密码摘要后应清空管理数据库中的 `web_sessions` 以撤销旧会话。

Vercel 项目目前通过 CLI 部署，GitHub 集成尚未获得新私有仓库权限。需要自动部署时，在 GitHub 为 Vercel App 授权对应的前端仓库，再连接仓库。不要从携带不被 Vercel 识别的 Git 作者信息的目录直接部署；可以将源码复制到不含 `.git` 和任何 `.env*` 的临时目录，复制 `.vercel/project.json` 后执行 `vercel deploy --prod`。

## 论文、图片和专家问答

- 文献研究阶段默认展示“Goal → 检索操作 → 选用文献与已解决问题 → Gap”的可缩放交互图谱（深色主题；没有检索或文献的阶段不占列，自动适配时不缩小到不可读，更大的图谱可拖动或用缩放按钮查看），点击节点查看依据，不展示原始 Markdown 阅读／编辑界面。目标复用项目状态，检索与 Wiki 阅读复用已有工具事件，论文和 Gap 直接解析 `literature/RESEARCH_REPORT.md`；MD 保留下载，不新增 skill 产物。Gap 仅关联正文明确提及的论文，历史事件缺失或输出截断时如实提示，可加载更早检索。研究进度可收起；对话区顶部仅显示当前工作的 Agent 与活动摘要，点击后展开当前任务及参与过的 Agent 执行记录，待命角色不占用主界面。
- 在工作区“产物”页签的文件选择器中打开 `.tex`：默认直接进入可编辑的 LaTeX 高亮编辑器，与已有 PDF 双栏对照；桌面默认为论文工作区分配更多宽度，支持全屏、PDF 文件选择、源码保存和未保存离开保护。手机端切换查看源码或 PDF。保存源码不会编译 PDF，PDF 工具栏显示“待编译”状态；重新生成 PDF 使用“运行设置 → 起始阶段 → 编译交付”，如仅需该阶段也将“运行至”设为“编译交付”。这沿用真实工作流，会调用现有工具，请核对运行参数。
- 研究精炼阶段在“研究方案”中审阅模型方案，“按此方案继续”批准当前正式方案。若项目里还留有旧版方案审阅页生成的草稿（`refine-logs/IDEA_CANVAS.json`、`IDEA_REVIEW.json`），后端会拒绝直接批准；此时页面显示琥珀色提示卡，说明草稿内容，并提供两种处理方式：“让 Agent 按草稿修订方案”（把草稿意见交给 Agent 写入正文后重新提交审阅）或“归档草稿，按当前方案继续”。两种方式都会先把草稿移到 `refine-logs/archive/` 保留，不会删除。
- “图片”页签集中查看 PNG/JPEG/WebP，点击打开缩放、旋转及前后切换预览。Markdown 内的相对图片路径只解析到已登记的项目图片，不自动加载外部链接或 SVG。
- 输入框下方的“专家模式 / 全自动”切换协作方式（专家模式每阶段完成后暂停等你审阅；运行中或有待审阅检查点时锁定，悬停可看原因），“运行设置”打开启动/继续窗口；切换在下一次节点运行时生效，不修改正在执行的任务。已有待审阅检查点必须先完成审阅。专家问题仅在阶段完成并等待审阅时出现，问题展示在左侧研究对话中，可在底部输入反馈，留空确认后继续。提交前仍需确认，系统校验检查点与产物版本。

工作台采用对话与产物双栏，两栏占满页面主体：左侧研究对话提交研究目标、补充指令和专家反馈，并展示真实阶段事件和模型公开回复；右侧工作区的标题与“产物 / 图片”页签合并在同一行。顶部研究进度默认收起为一行，显示项目名称、完成数和 11 段迷你进度条；点“展开”查看完整进度条（只占一行高度，不挤压对话和工作区），展开或收起的选择保存在本机浏览器。点击任一阶段：右侧打开该阶段产物，左侧对话同时滚动到该阶段开始的位置并短暂高亮；阶段还没有产物时只定位对话并提示。工作区标题旁的“N 个产物 ▾”直接展开产物选择器，选择器左侧标注当前产物所属阶段。

对话中两条消息之间连续的工具调用、任务交接和进度通知合并为一个“执行过程”块：运行中保持展开，标题显示正在执行的步骤、步数和用时；结束后折叠为“已完成 N 步”的一行摘要，可展开查看每一步，点击单步查看调用参数与输出。模型错误、运行结果和阶段完成仍单独显示。模型若返回思考内容（DeepSeek、Qwen 等 OpenAI 兼容接口的 `reasoning_content` / `reasoning`），对话中显示“思考过程”块：思考时自动展开并逐字流式显示，完成后折叠为“已思考 N 秒”，可点开阅读；思考内容只用于展示，不会再发给模型。不返回思考内容的模型，在 Agent 工作且尚无回复文本时，对话底部显示“正在思考”提示和已用时。流式回复先进入缓冲区再按自适应速度逐字显示（落后越多追得越快），新内容带光晕渐显，末尾有闪烁光标；系统开启“减少动态效果”时直接显示全文。右侧“产物”页签的文件选择器提供路径搜索；Markdown 报告只读，以阅读视图打开，不提供编辑、保存或下载；LaTeX 直接进入源码编辑并与 PDF 对照，按 Ctrl / ⌘ S 保存（没有单独的保存按钮），编辑器工具行显示“未保存 / 已同步”状态。对话区顶部以紧凑状态栏显示当前工作的 Agent，点击展开任务和执行记录筛选。拖动中间分隔条（或聚焦后按左右键）调整比例，“展开工作区”将全部空间交给产物；窄屏通过“研究对话 / 产物工作区”切换，保留 LaTeX 编辑草稿。右侧工作区较窄时，LaTeX 源码与 PDF 通过面板切换查看。

新项目在启动研究前先判断消息意图：普通问题直接回答，研究主题不明确时先追问，只有明确的研究请求才创建工作流。普通对话保存在项目事件中，刷新后可以恢复；判断失败保留输入并提示重试。已有研究的恢复与专家反馈继续沿用原有流程。

专家审阅按问题展示独立回答框，显示已回答数量，底部支持选填补充意见。提交时将已填写的问题与回答一并发送，保留原有检查点版本校验；取消或提交失败保留当前填写内容，成功后清空。未回答的问题表示接受当前建议，合并反馈最多 20,000 字。

执行记录通过 `/api/projects/{id}/activity` 分页恢复，SSE 推送增量。SSE 连通时，工作台不再定时轮询：收到新事件后统一刷新项目状态、文件列表和当前打开的产物，发送消息或启动运行后立即补读一次执行记录。另保留低频核对防止漏消息：执行记录 30 秒，项目状态 30 秒（有运行时 8 秒，因为终端启动的运行不产生事件），文件列表 60 秒，运行中打开的产物 15 秒；SSE 断线时回到 4 秒（项目）、5 秒（执行记录）、10 秒（文件）的轮询，重连后自动恢复。支持加载较早记录。工具输出最多记录 6,000 字符，模型公开回复最多 20,000 字符，思考内容按提供方实际返回的展示，不另行推测。旧运行未保存的回复无法还原，只展示已有阶段产物与已持久化进度。模型回复随生成逐字出现，工具调用与阶段进度实时更新。新增事件记录需要使用更新后的后端及新启动的研究进程。

布局保持视口高度，对话、报告、源码、PDF、文件列表和画廊分别滚动；“运行动态”保留原始日志抽屉。滚动样式集中在 `src/features/workbench/workbench.css`，布局父链保留 `min-height: 0`，编辑器使用父容器高度。

## 视觉主题与动效

界面使用“石墨夜”深色主题。颜色全部定义在 `src/app/theme.css` 的 CSS 变量中（底色、文字、品牌渐变 `--charge-a` → `--charge-b`、需处理事项的琥珀色 `--attn` 等），其他样式只引用变量；改配色只需修改这一处，antd 主题 token 在 `src/main.tsx` 中同步设置。Monaco 编辑器与 React Flow 图谱使用对应的深色主题。英文与数字字体 IBM Plex Sans / Mono 通过 `@fontsource` 本地打包，中文使用系统字体，不依赖外部字体服务。

动效集中在 `src/components/fx/`、`src/app/effects.css`、`src/features/workbench/workbench-fx.css` 与 `charge-track.css`：

- 产品首页：标题逐字升起，第二行为流动的充能渐变；背景是缓慢漂移的极光、向前流动的透视网格和粒子；右侧“循环老化测试”面板逐条绘制放电曲线（容量随循环衰减），下方的健康度点与寿命预测虚线同步推进，读数随之变化（示意数据，不来自真实项目）。研究流程和能力卡片滚动进入视野时依次点亮。
- 充能跳转（`ChargeTransition`）：从首页进入工作台时，全屏遮罩从点击处圆形展开，中央电池按真实预加载进度充能，同时并行获取研究引擎状态、项目列表和界面字体，并逐项显示“就绪”；至少显示 1.3 秒、最多等待 5 秒，失败项不阻塞跳转，由目标页面自己显示加载或错误状态。充满后闪光、跳转，再模糊淡出。
- 启动画面：`index.html` 内联一个充电动画，在脚本下载期间显示，React 首帧渲染后淡出移除。
- 首页、项目列表与登录页的粒子连线背景（`ParticleField`），随鼠标吸引，离屏或标签页隐藏时暂停。
- 全局鼠标光晕；带 `spotlight` 类的卡片边框随鼠标发光，带 `tilt` 类的卡片随鼠标 3D 倾斜（`AmbientEffects`）。
- 能量爆发（`burst`）：带 `data-burst` 属性的按钮点击时触发，阶段完成时在进度条上触发并显示“+1 阶段完成”。
- 研究进度条：已完成阶段依次充能，运行中阶段显示流动斜纹和电流光点，等你审阅的阶段与审阅卡片琥珀色呼吸发光。
- 页面切换模糊浮现（`motion`）、统计数字滚动、运行状态流光文字、主按钮扫光。

系统开启“减少动态效果”（`prefers-reduced-motion`）时，上述动画自动关闭或改为静态。

## 电池范式库与电池资源库

导航栏提供“电池范式库”和“电池资源库”，分别对应 `/libraries/paradigms` 与 `/libraries/battery`。页面支持正文搜索、分类筛选、Markdown/公式/表格阅读、库内文档跳转及图片和 PDF 查看；手机端可在目录和正文之间切换。文档路径、搜索与分类保存在 URL，支持刷新和分享。

内容直接读取后端资源目录，点击刷新即可重新读取；当前提供只读浏览。后端目录及接口配置见 `batteryscientist/docs/web.md`。

电池范式库首页为关系图谱，基于 Wiki 中的真实节点与 `graph/edges.jsonl` 关系绘制，支持缩放、平移、缩略图、类型筛选和关键词定位；点击节点以侧边文档面板阅读，关闭后继续浏览图谱。未记录关系的条目不自动推断连线。电池资源库继续使用分类目录阅读。

电池范式库新增“论文图片”视图（`?view=figures`），展示归档图片对应的论文名称、图号、PDF 页码和原图注，支持放大预览、论文筛选、名称/图注搜索；存在论文条目时可点击名称打开文档。读取 `figures/<paper-id>/<image>` 及同名 `.md` 的 Source/PDF page/图注元信息，缺失论文条目时使用 sidecar 中的 `Paper title:`。

工作区文件选择器按论文、图表、研究报告、实验数据、代码配置和运行日志分组，组内保留真实目录层级；可搜索文件名或完整路径。此目录仅整理展示，不移动项目文件。

## 物理实验室

导航“物理实验室”（`/laboratory`）提供“新威 BTS”和“自动化扣电”两个页签，后者暂留空。BTS 按设备、单元展示通道卡片，包含真实运行状态、电压、电流、容量、能量；支持设备选择、状态筛选、搜索及点击查看通道详情。每 10 秒自动刷新，可暂停或手动刷新，断线保留数据并明确标记“未更新”。

数据通过受登录保护的 `/api/laboratory/bts` 获取，由后端连接实验室 MCP 服务。后端需安装 MCP 依赖并启用 `laboratory` 阶段，配置见 `batteryscientist/docs/web.md`；无需在浏览器配置设备地址或令牌。页面不提供设备控制。交互回归：`npx playwright test tests/laboratory.spec.ts`。
